# FastAPI + PostgreSQL CRUD API

A REST API for item management, built with **FastAPI** and **PostgreSQL**. Requests and responses are validated with Pydantic schemas, and the database is accessed through SQLAlchemy.

## Tech stack

- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- Uvicorn

## Endpoints

| Method | Path | What it does | Success response |
|---|---|---|---|
| GET | `/` | API status message | `200` — `{"message": "API is up and running!"}` |
| POST | `/items/` | Create a new item | `201` — the created item |
| GET | `/items/` | List all items | `200` — array of items |
| DELETE | `/items/{item_id}` | Delete one item | `204` — no content (`404` with `"Item not found"` if the id does not exist) |

## Item fields

| Field | Type | Required | Notes |
|---|---|---|---|
| `title` | string | yes | |
| `description` | string | no | optional |
| `price` | float | yes | |

Responses also include `id` and `created_at`, which are generated by the database.

## Example — create an item

Request:

POST /items/
Content-Type: application/json

{
  "title": "Notebook",
  "description": "Ruled, A5",
  "price": 350.0
}

Response (201):

{
  "id": 1,
  "title": "Notebook",
  "description": "Ruled, A5",
  "price": 350.0,
  "created_at": "2026-09-17T10:15:30"
}

## Run it locally

1. Clone this repo and create a virtual environment.
2. Install the dependencies (`pip install -r requirements.txt`).
3. Create a PostgreSQL database and set your connection string in a `.env` file (never commit real credentials).
4. Start the server: `uvicorn app.main:app --reload`
5. Open the interactive docs at `http://127.0.0.1:8000/docs`.
